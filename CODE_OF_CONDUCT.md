# Code of conduct

This repository asks people to question claims. That only works if the questioning stays respectful.

- **Criticise the work, not the person.** "This lemma does not say what the README says" is welcome. Personal attacks are not.
- **Be patient with newcomers.** Many readers here are not scientists. Explain, or point to an explanation.
- **Be honest.** Do not present guesses as checks, and do not invent results. That rule applies to us first.
- **No harassment.** That includes insults, threats, discrimination and unwanted personal attention.

The maintainer may edit, hide or close comments and issues that break these rules, and may block repeat offenders. To report a problem, open an issue, or use GitHub's reporting tools if the matter is private.
